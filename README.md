# Nomade — Travel Agency Website

Modern, interactive travel agency website crafted with Next.js, React, Tailwind CSS, Framer Motion, and GSAP.

## Features
- **Hero Canvas Scroll Animation**: Smooth dynamic sequence playback.
- **Curated Travel Escapes**: Coastal retreats, water adventures, cultural journeys, and mountain trails.
- **Constellation Testimonials**: Interactive particle & floating traveler story reviews.
- **Global Travel Network**: Dotted world map showing connected routes.
- **Interactive Search Widget**: Seamless filters for residences, hotels, and vacation rentals.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
